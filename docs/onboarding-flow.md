# Onboarding Flow

## Wizard Steps
1. Admin auth bootstrap complete.
2. Workspace defaults and team setup.
3. Cloud provider metadata configuration.
4. Observability connector setup.
5. AI provider and embedding provider setup.
6. Knowledge source ingestion kickoff.
7. Test webhook dispatch.
8. Test incident creation.
9. Health verification and completion.

## Current Backend Support
- Step updates persist via provider configuration records.
- Status endpoint returns progress checks.
- Connectors and providers are managed via integration endpoints.
